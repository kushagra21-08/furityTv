# Phone Controller Game Console

> A proof-of-concept for turning smartphones into low-latency game controllers for a TV or browser-based game over a local network.

## Overview

This project explores how multiple phones can connect to a game running on a TV (or any browser) and act as wireless controllers.

The focus is on:
- Low latency
- Local network communication
- Browser-based technology
- No dedicated game engine
- Learning networking from first principles

---

## Goals

 Connect phones to a host device
  Send controller inputs in real time
 Display the game on a TV/browser
 Support multiple players  Keep latency as low as possible
 Learn networking and game architecture

---

## Planned Features

### Phone Controller
- Touch buttons
- Virtual joystick
- Gyroscope controls
- Vibration feedback
- QR code pairing

### Host/Game
- Display game on TV/browser
- Receive player inputs
- Manage game state
- Multiplayer support
